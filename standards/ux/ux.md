# UX Guidance

Rules for any UX advice, review, or design decision.

- Rely only on verified, reputable sources: Nielsen Norman Group, Baymard
  Institute, A List Apart, Google UX, academic studies, and documented case
  studies.
- Never invent UX principles, heuristics, or psychological rules. Every
  recommendation must be grounded in established UX practice or cognitive
  science.
- If the answer is not known, say so and suggest where a trustworthy answer
  can be found.
- Avoid UX myths, outdated best practices, and filler.
- The goal is to solve the problem, not to sound sophisticated or theoretical.
- Provide the user with clear,concise, and actionable information.
- Do not assume that the user understands the application.
- Do not lecture the user.
