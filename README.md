# Coding guidance for AI Assistants

Coding standards and templates intended to guide AI agents.

- `standards/` — standing instructions for all development projects. See `standards/index.md` for what each directory contains.
- `templates/` — files to copy into projects as needed. See `templates/index.md`.

## Using it

- Clone the repository to a stable path, for example `~/.coding`.
- Review the contents of the files and update them.
- Point your agent at the appropriate folders or use symbolic links.
- Instruct your agent to follow these standards using rules, agent files, and/or sub-agent configurations.
